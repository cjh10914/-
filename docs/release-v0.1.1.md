# MaintainerFlow v0.1.1 — Open-Source Credibility Update

MaintainerFlow v0.1.1 focuses on publishability and contributor confidence rather than major new features.

## What changed

### Repository credibility
- README now includes badges, clearer positioning, project status, and a stronger quick-value statement.
- Added explicit guidance on who MaintainerFlow is for (and not for).
- Added realistic output examples linked directly from the README.

### Community and maintenance
- Added `CODE_OF_CONDUCT.md`, `SECURITY.md`, and `SUPPORT.md`.
- Added GitHub issue templates (bug, feature request, question) and a pull request template.
- Improved `CONTRIBUTING.md` with a simple local dev + review workflow.

### Release readiness
- Added a release checklist in `docs/release-checklist.md`.
- Updated `CHANGELOG.md` for v0.1.1.

## Limitations

MaintainerFlow remains deterministic and heuristic-based. It assists maintainers and does not replace human judgment, security review, or merge policy checks.
