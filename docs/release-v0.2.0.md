# MaintainerFlow v0.2.0 — Open-source credibility and usability update

MaintainerFlow v0.2.0 focuses on making the project easier to evaluate, adopt,
and contribute to for real OSS maintainer teams.

## Highlights

- Improved README clarity: stronger problem statement, audience fit/non-fit,
  realistic limitations, and a human-vs-automation comparison table.
- Better contributor guidance: clearer local setup, fixture conventions,
  review expectations, and how to propose deterministic rules/templates.
- Polished support/security docs and release checklist for maintainable OSS operations.
- CLI markdown output now includes clearer missing-information reporting and
  suggested next steps for triage/review workflows.
- Added application-ready project summary document for OSS program submissions.

## Scope and honesty

This release does **not** add speculative AI features, paid API requirements,
or autonomous-review behavior. MaintainerFlow remains deterministic and
assistive; human maintainer judgment is required for decisions.
