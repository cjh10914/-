# MaintainerFlow Roadmap

## Near term

- Add optional confidence calibration report for triage.
- Add richer PR diff parsing for renamed files and binary changes.
- Add release note templates for security advisories.

## Mid term

- Optional pluggable LLM backends behind a provider abstraction.
- Rule packs per repository (YAML configuration).
- Auto-comment mode for GitHub Actions with dry-run safeguards.

## Long term

- Multi-repo maintainer dashboard (outside MVP).
- Learning loop from maintainer overrides.
