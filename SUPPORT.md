# Support

## Where to ask for help

- **Usage questions:** open a GitHub issue using the **Question** template.
- **Bug reports:** use the **Bug report** template with reproducible input and output.
- **Feature ideas:** use the **Feature request** template.
- **Security concerns:** follow `SECURITY.md` (do not post publicly).

## What to include for faster help

- command you ran,
- input files (or sanitized snippets),
- expected vs actual output,
- Python version and operating system.

MaintainerFlow is an assistive maintainer tool. It does not provide autonomous
code review or security guarantees.
